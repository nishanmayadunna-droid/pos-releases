# Mayadunna POS — installers

Windows installers and automatic updates for the Mayadunna Traders POS.
This repository holds **installers only**; the source code is private.

Download the latest `Mayadunna-POS-Setup-*.exe` from **Releases** and run it. Installed tills update themselves.

> Windows may show "Windows protected your PC" (the installer is not code-signed yet): click **More info → Run anyway**.
